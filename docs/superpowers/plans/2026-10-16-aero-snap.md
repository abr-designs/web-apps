Created by Claude (claude-opus-5-5), 2026-10-16

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Aero Snap, a cozy third-person Frutiger Aero photo game with one island, 10 graded photo requests, a pocket gadget HUD and a persistent scrapbook.

**Architecture:** Static app in `apps/aero-snap/` using ES modules and Three.js through an import map. All game rules (day phases, island shape, movement math, critter timers, grading, progress, roll cap, frame guard) live in pure modules with no Three.js or DOM imports and are unit-tested with `node --test`. Three.js modules (world, critters, player, photo capture/analysis) and DOM modules (gadget, polaroid, scrapbook) wrap those pure modules and are verified in the browser preview.

**Tech Stack:** Vanilla HTML/CSS/JS (ES modules), Three.js `0.170.0` from jsdelivr (`build/three.module.js` and `examples/jsm/` addons: `EffectComposer`, `RenderPass`, `UnrealBloomPass`, `OutputPass`), IndexedDB, localStorage, Web Audio, Node 22+ `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-16-aero-snap-design.md`

## Global Constraints

- Zero npm dependencies, no build step, no `package.json`.

## Review Focus

- A subject mostly hidden behind a building is photographed: it must not match (`visibleRatio < 0.4`). Test in Task 2.
- `aero-snap:progress` holds invalid JSON or an unknown `version`: the game resets that store and starts, never throws. Test in Task 8.
- A new photo matches a request whose slotted photo has more stars: the keep prompt defaults to the old photo. Test in Task 8.
- The camera roll reaches 60 while every roll photo is slotted: nothing slotted is ever dropped, the roll may exceed 60. Test in Task 8.
- The tab is backgrounded for a minute and resumed: frame delta is clamped to 0.1 s so critters and the day cycle do not jump, and lost pointer lock returns `aim` to `explore`. Test (`clampDt`) in Task 1; pointer lock check in Task 9.
