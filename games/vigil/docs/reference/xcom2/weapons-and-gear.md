# Weapons and gear

Source tags are defined in [README.md](README.md#sources-and-tags). Markers: * Alien Hunters DLC, † War of the Chosen, ‡ Tactical Legacy Pack, § Shen's Last Gift DLC. "Crit +" is the bonus a crit adds on top of the normal damage roll (FD convention; UFO prints the total, which is base + bonus). Blank cells mean the source lists nothing.

## Primary weapons

Tiers run conventional, magnetic, beam (plasma). INI stores each weapon as base damage ± spread with a percent chance of +1 (assault rifle `Damage=4, Spread=1` = 3-5; pistol `Damage=2, PlusOne=50` = 2-3); the damage ranges below match it. Range-by-distance aim tables are in [combat.md](combat.md#range-modifiers).
